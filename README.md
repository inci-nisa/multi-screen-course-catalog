# Multi-Screen Course Catalog

A multi-screen mobile course catalog application built with **React Native** and **TypeScript**, enabling users to browse courses and navigate between screens for detailed course information.

## Features

- **Multi-Screen Navigation:** Seamless navigation between the main course list and course detail screens.
- **Course Browsing:** Structured display of available courses with key metadata.
- **Modular Component Architecture:** Separated screen and UI components written in TypeScript.

## Tech Stack

- React Native
- TypeScript
